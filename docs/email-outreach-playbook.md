# DigitalX Solutions — Automated 50-Daily Email Outreach Playbook

> **Target Capacity**: Exactly 50 emails per day (Hard capped by telemetry tracker)  
> **Target Verticals**: Trade Contractors (Plumbers, HVAC, Electricians), Dental & Healthcare Clinics, B2B Professional Services  
> **Engine Location**: `scripts/outreach/`  
> **Deliverability Posture**: Maximum Domain Protection & Spam Act / CAN-SPAM Compliance  

---

## 1. Engine Overview & Architecture

To reach 50 prospective clients daily without risking our primary domain (`digitalx-solutions.com`) getting flagged by spam filters or blocklists, the outreach engine implements a 5-layer deliverability shield:

```
[ Prospect Lead List (Seed or CSV) ]
               │
               ▼
1. Unsubscribe & 60-Day Duplicate Check (Local History Ledger)
               │
               ▼
2. Syntax Format & Role-Based Filter (Filters out abuse@, admin@, etc.)
               │
               ▼
3. Live DNS MX Record Verification (Drops unroutable domains before sending)
               │
               ▼
4. Vertical Template Personalization (Under 90 words, plain-text style, compliance footer)
               │
               ▼
5. Randomized Jitter Delay (45s–120s between sends to simulate human behavior)
               │
               ▼
[ Free Resend API (100 emails/day free) OR Nodemailer SMTP Relay ]
```

## 2. Quick Command Reference

All commands run through `npm`:

### A. Check Daily Telemetry & Remaining Quota
```bash
npm run outreach:stats
```
*Outputs current daily cap (50), emails sent today, remaining quota, lifetime contacts, and unsubscribed addresses.*

### B. Dry-Run (Preview Personalized Drafts Without Sending)
```bash
npm run outreach:dry-run
```
*Simulates the full run: validates syntax, checks live DNS MX records for each domain, renders personalized templates, and outputs email previews without firing real emails.*

### C. Live Send Execution
```bash
npm run outreach:send
```
*Connects to your configured delivery provider, applies the 45s–120s randomized human jitter delay, and sends up to your remaining daily quota (maximum 50/day).*

### D. Filter by Vertical
You can target a specific industry vertical:
```bash
npm run outreach:send -- --vertical trades
npm run outreach:send -- --vertical dental
npm run outreach:send -- --vertical b2b
```

### E. Load Custom CSV Leads
Drop your daily lead list into `data/leads.csv` or specify any CSV path:
```bash
npm run outreach:send -- --csv data/leads.csv
```
The CSV header must include `email`, and optionally `name`, `company`, `industry`, `city`, `country`, `website`.

## 3. How to Connect Free Sending Providers

The engine is engineered to work out of the box with zero paid subscriptions.

### Option 1: Resend (Recommended — 100 Emails/Day Completely Free)
1. Sign up at [resend.com](https://resend.com) (free tier includes 3,000 emails/month or 100/day).
2. Generate an API Key in the Resend dashboard.
3. Add it to `.env.local` or your environment:
   ```bash
   RESEND_API_KEY="re_xxxxxxxxxxxxxx"
   OUTREACH_FROM_EMAIL="ahsan@yourdomain.com"
   OUTREACH_SENDER_NAME="Ahsan Architect"
   OUTREACH_REPLY_TO="info@digitalx-solutions.com"
   OUTREACH_PROVIDER="resend"
   ```

### Option 2: Gmail / Google Workspace SMTP (Free Relay)
If sending directly from your Google Workspace or Gmail account:
1. Enable 2-Step Verification in Google Account Settings.
2. Generate a 16-character **App Password** under Security > 2-Step Verification > App passwords.
3. Add to `.env.local`:
   ```bash
   EMAIL_USER="your-email@digitalx-solutions.com"
   EMAIL_PASS="xxxx xxxx xxxx xxxx"
   SMTP_HOST="smtp.gmail.com"
   SMTP_PORT="465"
   SMTP_SECURE="true"
   OUTREACH_PROVIDER="smtp"
   ```

## 4. Legal Compliance & Deliverability Rules

Every email generated by `scripts/outreach/templates.ts` strictly satisfies:
1. **Australian Spam Act 2003**:
   - Clear identification of DigitalX Solutions (`16 Boldrewood Ave, Casula NSW 2170, Australia`).
   - One-step functional unsubscribe instruction (*"reply with 'unsubscribe' to be immediately removed"*).
2. **US CAN-SPAM Act**:
   - Non-deceptive subject lines directly referencing the recipient company.
   - Physical postal address rendered in email footer.
3. **Hard Bounce Shield**:
   - DNS MX queries run prior to sending. Any domain without active mail exchangers is logged as `skipped_invalid_mx`, preserving our sender score.
4. **Idempotency**:
   - If an email was contacted within the last 60 days, it is automatically skipped to prevent repeat messaging.

## 5. Daily Automation Routine (Recurring Cron / Task Scheduler)

To automate the 50 daily emails every weekday morning at 8:30 AM local time:

### On Windows (Task Scheduler via PowerShell):
```powershell
$action = New-ScheduledTaskAction -Execute "npm.cmd" -Argument "run outreach:send" -WorkingDirectory "C:\Users\DELL\.gemini\antigravity-ide\scratch\digitalx-solutions"
$trigger = New-ScheduledTaskTrigger -Daily -At 8:30am
Register-ScheduledTask -Action $action -Trigger $trigger -TaskName "DigitalX-Daily-Outreach" -Description "Sends 50 daily B2B outreach emails"
```

The script will automatically stop at exactly 50 emails per day and resume the next morning.
